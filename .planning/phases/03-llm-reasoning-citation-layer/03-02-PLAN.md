<objective>
The LLM server layer: Lightning structures the only unstructured inputs (PT/MT notes + component/service context) into a Zod-validated evaluation context pack — once per evaluation, batched — and Super-120B narrates per opened pane strictly around a precomputed-values prompt, policed by four server-side lints with the deterministic fallback as the only rejection path. Fails loudly at extraction (SC1), never serves a contradicting narrative (SC2), references PT/MT engine verdicts as ground truth (SC4), and captures real usage metadata for the status bar (PLAT-05).

Purpose: this is the phase's credibility core — the LLM touches nothing but glue, and every escape route leads to the fallback, never to a fabricated number or citation.

Artifacts this phase produces (this plan): `/api/reasoning/extract` route, the enabled path of `/api/reasoning/narrative`, the narrative-context/prompt/lint modules, and the live-gated fixture proof.

Success criteria served: SC1, SC2, SC4, PLAT-05 (capture half — badges render in 03-04).
</objective>
