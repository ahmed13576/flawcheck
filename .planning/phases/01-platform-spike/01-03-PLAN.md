<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser -> /api/health | Unauthenticated read of validation status; response must not leak secrets |
| Browser -> /api/spike/stream | Unauthenticated POST that triggers paid model calls; body crosses the trust boundary |
| Token Factory -> route handler -> browser | Model output is re-encoded and relayed; only delta text reaches the client |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Information Disclosure | /api/health response | medium | mitigate | Body limited to status, missing[], checkedAt, optional error — never the key, never the full catalog (Pattern 4 + RESEARCH.md Security Domain) |
| T-03-02 | DoS (SSRF/abuse surface) | /api/spike/stream POST | medium | accept | Unauthenticated by design in Phase 1 (PLAT-04 abuse guarding is Phase 5 via proxy.ts); dev server binds localhost by default; this route must NOT be deployed publicly before Phase 5 guarding; prompt body validated (400) before any paid call |
| T-03-03 | Information Disclosure | client bundle / spike page | high | mitigate | No key reads outside lib/llm/*; the page receives only streamed delta text and health booleans/IDs; verified by the source-clean grep and the health-body field whitelist |
| T-03-04 | Tampering | request body to stream route | low | mitigate | Parse-boundary validation: non-string or empty prompt returns 400 before any model call (ASVS V5) |
</threat_model>
